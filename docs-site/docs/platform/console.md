# 控制台使用指南

控制台是 Whaleal SMS 的操作面：登录后可手工发信、看全渠道日志、管渠道与密钥、查用量。这一页按侧边栏分组逐块讲清楚**每个页面解决什么问题**。

登录入口 [sms.whaleal.com](https://sms.whaleal.com)，走 **Whaleal IDP** 统一身份，首次登录即建租户。

## 发送短信：三种用法

发送页把「单发」和「批量群发」分开，因为两者的路由语义不同。

### 单发 — 不选渠道时走默认路由链

填目标号码（**E.164 格式**，如 `+8613800000000`）和内容就能发。**渠道是可选字段**，两种语义差别很大：

| 渠道选择 | 行为 | 适用 |
|---|---|---|
| **不选**（默认路由） | 系统自动在**已绑定的渠道与 Sender 之间平滑加权轮询**，失败自动容灾切换 | 正常业务发送 |
| **选定某条** | 整条只走该渠道（渠道内多 Sender 仍按权重轮询） | **自测某条通道是否可用** |

### 批量群发 — 走批次 + 模板

批量发送需要先在**联系人**页导入号码（导入时会自动生成批次），然后在发送页选「联系人批次 + 发送渠道 + 模板」。任务会**自动限速、分批下发**，不会一次性把渠道打满。

注意批量与单发的路由语义不同：**整批只走所选渠道**，渠道内多 Sender 仍按权重轮询、失败在该渠道内容灾。

### 发送前就能看到计费条数

内容框旁边有实时计数器，显示**编码口径 · 单位数 · 计费条数**三件事，批量时还会给出「预计计费 N 条（联系人 × 每条 S 条）」。

> 这是平台上很实用的一处设计：**你在点发送之前就知道这条短信在账单上算几条**，不必等出账才发现长短信被拆分计费。

如果正文含目标编码无法表示的字符，页面会**直接阻止发送并给出原因** —— 此时要么改正文，要么把渠道编码改成「自动判定 / UCS-2」。

### 定时发送

发送页勾选「定时发送」并选计划时间，任务会进入**定时发送**队列，到期自动分批下发。随时可在侧边栏「定时发送」页查看队列。

## 数据与集成

### BYOL 渠道 —— 一切的起点

录凭据、加 Sender、设 priority / weight。详细步骤见 [接入方式总览 · 第 1 步](getting-started.md)。

> 发送页如果提示「暂无可用渠道」，就是这个页面还没配置或渠道未启用。

### API 密钥 —— 程序化发信的凭据

签发 `sk_` 密钥、绑定可用渠道、查看路由链。两条要点：

- **明文只展示一次**，平台只存哈希
- **未绑定渠道的密钥发不了信**（调用直接被拒）

完整步骤见 [接入方式总览 · 第 2 步](getting-started.md)。

### 消息日志 —— 排障主入口

这是日常用得最多的页面。可以按**手机号、状态、供应商**三个维度筛选，列表给出时间、接收号码、供应商、Sender、状态与计费信息，并支持**按当前筛选条件导出**。

状态取值与开放 API 一致：`submitted`（已提交） / `delivered`（已送达） / `failed`（失败） / `rejected`（被拒）。

> 🔴 **这个页面是「超时不重发」的兜底手段**。发送超时又没拿到 `messageId` 时，到日志页按**时间窗 + 接收号码**查一下是否已经发出 —— 查到了就**不要再重发**。[原因见这里](open-api.md#no-resend)。

> 历史记录（编码口径功能上线前）的计费字段为空，属正常现象，不是数据丢失。

### 数据报表

把各渠道的发送表现放在一起看。多渠道并行时，这里是判断「哪家通道最近质量变差」最直接的地方。

## 系统

| 页面 | 用途 |
|---|---|
| **套餐与计费** | 当前档位、本月用量、订阅管理。档位差异见[套餐与配额](plans.md) |
| **开发者中心** | 配置状态回调地址、复制供应商回执地址、生成/重置回调令牌。见[状态回调接入](callback.md) |
| **用户中心** | 账号与显示名；用户资料由 Whaleal IDP 托管，平台不另存 |

## 控制台和 SDK 怎么分工

控制台不只是"配置页"，它本身就是一个可用的发送面：

| 场景 | 用哪个 | 为什么 |
|---|---|---|
| 验证码、通知等**程序化**发送 | 开放 API | 要进业务链路 |
| 运营**临时**发一条公告 | 控制台发送页 | 不用为一次发送写代码 |
| **群发**给一批联系人 | 控制台批量 + 模板 | 自动限速分批，不必自己实现队列 |
| **预约**发送（活动提醒） | 控制台定时发送 | 队列由平台托管 |
| 自测**某条通道**通不通 | 控制台发送页选定该渠道 | 单发选定渠道 = 整条只走它 |
| **排障**：这条到底发出去没有 | 控制台消息日志 | 时间窗 + 号码直接查 |
| 想在自己系统里直连 CPaaS | [Quick SMS SDK](../intro.md) | 与平台共享同一批账号，互不冲突 |
